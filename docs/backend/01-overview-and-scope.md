# Backend Overview and Scope

This backend powers a single wealth view for customers who invest in different asset types and currencies.

## What the customer gets in v1

- One dashboard for total invested amount, current value, and gains/losses
- Realized and unrealized P/L visibility
- Daily portfolio history for trend charts
- Milestone tracking tied to wealth goals
- Multi-currency support with base-currency reporting

## What is included

- Create and maintain investments
- Record and review transactions
- Consolidate portfolio metrics for dashboard reporting
- Capture daily snapshots for historical performance
- Configure base currency and exchange rates

## Why this scope works

The first release focuses on business clarity and reliability instead of feature overload. It covers all required outcomes while keeping room for fast future additions.
